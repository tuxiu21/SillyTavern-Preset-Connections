# SillyTavern 预设对应连接

选择聊天补全预设时，自动加载对应的整套 API 连接配置，包括模型、接口和保存的密钥选择。

## 安装

打开酒馆的 **扩展 → 安装扩展**，粘贴仓库地址：

```text
https://github.com/tuxiu21/SillyTavern-Preset-Connections
```

安装后刷新页面。需要支持扩展 `activate` 生命周期、API 连接配置和 `getPresetApplicationPromise` 的新版 SillyTavern。

## 使用

1. 提前在酒馆中保存好 API 连接配置，确认其模型和密钥选择正确。
2. 选择要关联的聊天补全预设。
3. 在预设下方新增的 **对应连接配置** 中选择连接，点击 **保存对应关系**。
4. 以后在预设下拉框中选择这个预设，就会自动加载对应连接。

### Vertex AI：JSON 与快速模式

酒馆原生连接配置未保存认证方式。对于 Vertex AI 连接，本扩展提供额外的 **Vertex AI 认证方式** 下拉框：选择 **JSON 服务账号** 或 **快速模式（API Key）**，再保存对应关系。保存前需在 API 面板中选好该认证方式使用的凭据。扩展仅记录原生凭据选择 ID，不读取 JSON 内容或密钥值。

选择 **跟随预设** 时沿用酒馆原有逻辑。认证方式选项仅在直接通过预设自动切换连接时恢复；手动选择原生连接配置仍遵循酒馆行为。

保存对应关系时，也会把该连接配置自身记录的预设改为当前预设，避免连接加载时切回旧预设。每套连接只能关联一个预设；若多个预设需要相同连接，请先复制连接配置。

酒馆原有的绿色链条保持独立。即使它开启，本扩展也会在预设加载完成后应用连接配置，因此连接配置中记录的模型最终生效。

选择“不自动切换连接”并保存即可解除关联。解除关联不会恢复连接配置之前记录的预设。

## 行为说明

- 仅直接操作预设下拉框时自动切换。通过连接配置、命令或其他扩展加载预设时，不触发反向切换，避免循环。
- 刷新页面不会主动切换连接；没有关联的预设保持酒馆原有行为。
- 关联使用连接配置 ID，重命名连接不影响关联；删除连接后不会自动选择其他连接。
- 若之后修改了连接配置中的预设，需重新保存对应关系。
- 本扩展不发送聊天消息，不新增密钥存储，也不上传连接配置；密钥仍由酒馆原生连接配置管理。
- 关闭或卸载本扩展并刷新后，自动切换停止。需要时可手动恢复连接配置原先的预设。
